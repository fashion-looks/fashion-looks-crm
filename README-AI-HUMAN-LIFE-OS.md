# AI Human Life OS — Amit Singh × Fashion Looks™

A local-first personal operating system prototype for daily planning, routines, business tracking and review.

## Features
- Daily task planner with priorities and due dates.
- Rule-based daily suggestions and copyable AI prompt.
- Fashion Looks textile-certification client pipeline.
- Actual receipt tracking.
- Daily habit checklist and 90-day / long-term goals.
- Daily review and JSON backup/import.

## Run
Open `ai-human-life-os.html` in a modern browser or host it as a static site. No API key required.

## What is automated
Changes are saved automatically in the browser's localStorage. This version does not run background jobs, sync to cloud, send reminders when the page is closed, call an LLM automatically, message clients, or perform transactions. Those features require authenticated backend services, scheduled jobs and explicit permissions.

## Privacy
Data remains in the current browser unless you export it. Do not store passwords, payment credentials, government IDs or confidential client information. Export backups regularly.
